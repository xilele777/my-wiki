---
title: 在前端框架中，如何声明并封装一个自定义组件？
---
在 React 和 Vue 中封装自定义组件的核心思路是一致的：**接收外部数据（Props）、管理内部状态（State）、向父级传递事件（通信）**。但两者的语法和实现哲学有显著差异。

下面是 React（函数组件 + Hooks）和 Vue 3（组合式 API + `<script setup>`）的对比实现，我们以封装一个**带展开/收起功能的卡片组件（Collapsible Card）**为例。

---

### 1. React 版本 (函数组件 + JSX)

React 遵循“所有数据都是 props，通信靠回调函数”的原则。

```jsx
// CollapsibleCard.jsx
import React, { useState } from 'react';

// 1. 声明组件：接收 props
// 2. 外部传参：通过 props 解构
// 3. 向父传参：通过 props 回调函数 (onToggle)
// 4. 内容分发：通过 props.children 或自定义 prop (如 header)
const CollapsibleCard = ({ 
  title, 
  children, 
  defaultExpanded = false, 
  onToggle // 父组件传入的回调
}) => {
  // 内部状态：使用 useState
  const [isExpanded, setIsExpanded] = useState(defaultExpanded);

  // 处理内部逻辑并通知父组件
  const handleToggle = () => {
    const newState = !isExpanded;
    setIsExpanded(newState);
    // 通知父组件（React 中显式调用回调）
    if (onToggle) {
      onToggle(newState);
    }
  };

  return (
    <div className="card">
      {/* 标题区域，点击切换 */}
      <div className="card-header" onClick={handleToggle}>
        {/* 支持父组件自定义标题结构 */}
        <h3>{title}</h3>
        <span>{isExpanded ? '▲' : '▼'}</span>
      </div>
      {/* 内容区域：根据状态渲染 */}
      {isExpanded && (
        <div className="card-body">
          {children}
        </div>
      )}
    </div>
  );
};

// 使用时：
// <CollapsibleCard title="用户协议" onToggle={(v) => console.log(v)}>
//   <p>这里是协议详情内容...</p>
// </CollapsibleCard>

export default CollapsibleCard;
```

---

### 2. Vue 3 版本 (单文件组件 SFC + `<script setup>`)

Vue 遵循“模板即视图”，通信靠 `props` 向下传，`emits` 向上发。

```vue
<!-- CollapsibleCard.vue -->
<template>
  <div class="card">
    <!-- 标题区域，点击触发切换事件 -->
    <div class="card-header" @click="handleToggle">
      <!-- 支持父组件通过插槽（slot）自定义标题 -->
      <slot name="header">
        <h3>{{ title }}</h3>
      </slot>
      <span>{{ isExpanded ? '▲' : '▼' }}</span>
    </div>
    <!-- 内容区域：使用 v-if 控制渲染 -->
    <div v-if="isExpanded" class="card-body">
      <!-- 默认插槽，用于分发内容 -->
      <slot />
    </div>
  </div>
</template>

<script setup>
import { ref, watch } from 'vue';

// 1. 声明接收外部 Props
const props = defineProps({
  title: {
    type: String,
    default: '默认标题'
  },
  defaultExpanded: {
    type: Boolean,
    default: false
  }
});

// 2. 声明向父组件传递的事件 (Vue 中必须显式声明 emits)
const emit = defineEmits(['toggle']);

// 3. 内部状态：使用 ref
const isExpanded = ref(props.defaultExpanded);

// 4. 处理逻辑并触发事件
const handleToggle = () => {
  isExpanded.value = !isExpanded.value;
  // Vue 中通过 emit 触发事件，传递参数给父组件
  emit('toggle', isExpanded.value);
};

// 可选：若外部 props 变化（如父组件重置状态），同步内部状态
watch(() => props.defaultExpanded, (newVal) => {
  isExpanded.value = newVal;
});
</script>

<!-- 使用时（父组件） -->
<!-- <CollapsibleCard title="用户协议" @toggle="(v) => console.log(v)">
  <p>这里是协议详情内容...</p>
</CollapsibleCard> -->
```

---

### 3. 核心差异总结（封装视角）

| 对比维度 | React | Vue 3 |
| :--- | :--- | :--- |
| **组件声明** | 函数/Class，返回 JSX | `.vue` 文件，`<template>` + `<script>` |
| **Props 定义** | 函数参数解构（无显式类型校验时无强制声明） | `defineProps` 宏声明，支持类型和默认值校验 |
| **内部状态** | `useState` 钩子，返回 `[值, set函数]` | `ref` 或 `reactive`，通过 `.value` 修改 |
| **向父通信** | 将回调函数作为 `props` 传入，调用回调 | `defineEmits` 声明事件，`emit('事件名', 数据)` |
| **内容分发** | `props.children`（默认）或传递 React 元素作为普通 prop（具名插槽） | `<slot>` 标签（默认），`<slot name="header">`（具名插槽） |
| **外部影响内部** | 无自动响应，需配合 `useEffect` 监听 props 变化 | 可使用 `watch` 监听 props 变化来重置内部状态 |

---

### 总结

- **React** 是 **“手拉手”模式**：数据流完全依赖函数传参，父子通信依靠回调函数透传，组件封装就是“编写一个纯函数或使用 Hooks 的闭包”。
- **Vue** 是 **“声明式协议”模式**：通过 `props`、`emits`、`slots` 三个明确的编译宏定义组件接口，框架自动处理响应式依赖和父子通信。

两者最终都能实现高内聚、低耦合的组件封装，但 **Vue 的 SFC 更接近 HTML 原生语义**，而 **React 的 JSX 更依赖 JavaScript 的逻辑表达能力**。
