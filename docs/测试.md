这是因为主页缺少 **Netlify Identity 的 JS 监听脚本**。

虽然邀请链接带着 Token 跳回了主页，但因为主页（`docs/index.md` 生成的页面）没有装“接应脚本”，所以无法自动弹出来设置密码的窗口。

### 补救方法（只需两步）

#### 第一步：在后台页面手动输入 Token

1. 复制你邮件邀请链接中 `#invite_token=` **后面的那一长串字符串**。
2. 直接在浏览器访问你的后台地址：`https://你的站点域名/admin/#invite_token=复制的那串Token`
3. 敲回车，此时后台的 `index.html`（因为我们写了 `netlify-identity-widget.js`）就会强行识别这个 Token，并在页面上弹出设置密码的窗口！

---

#### 第二步：在 VitePress 全局引入 Identity 脚本（一劳永逸）

为了防止以后重置密码或其他人接收邀请时再出现“跳回主页没反应”的情况，我们在 VitePress 的配置里把监听脚本全局挂载上：

打开 `.vitepress/config.mjs`，在导出的配置对象中加上 `head` 属性：

```js
// .vitepress/config.mjs
export default {
  title: "我的知识库",
  description: "VitePress + Decap CMS Wiki",
  
  // 加上这一段，在所有页面的 <head> 里自动注入 Netlify Identity 脚本
  head: [
    ['script', { src: 'https://identity.netlify.com/v1/netlify-identity-widget.js' }]
  ],

  themeConfig: {
    // ...你原本的配置保持不变
  }
}

```

改完后用 `git commit` 和 `git push` 推送到 GitHub，Netlify 会自动重新打包。以后无论点什么验证链接，跳回主页时都会自动弹出密码设置框了！
